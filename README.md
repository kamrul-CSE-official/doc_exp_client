# Mini Workspace Explorer

A browser-based file manager built with Next.js and TypeScript.

## Project Links

- **GitHub Repository:** https://github.com/kamrul-CSE-official/doc_exp_client
- **Live Demo:** https://doc-exp-client.vercel.app/

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Redux Toolkit
- Redux Persist

## Features

- Create folders
- Create text files
- Nested folder navigation
- Expand/collapse folders
- Select folders
- Rename files and folders
- Delete files and folders
- Recursive folder deletion
- Text file editor
- Save file content
- Workspace-wide search
- Search through nested folders
- Breadcrumb navigation
- Browser persistence
- Responsive interface

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

```bash
git clone https://github.com/kamrul-CSE-official/doc_exp_client.git
cd doc_exp_client
pnpm install
```

### Run Development Server

```bash
pnpm dev
```

Open http://localhost:3000 in your browser.
